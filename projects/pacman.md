title: PacMAN
description: PacMAN is a UNESCO-IOC initiative that created a molecular monitoring framework to detect marine invasive species in Pacific Island States using eDNA and qPCR techniques. The project built local scientific capacity while developing an interactive decision-support dashboard that translates genetic data into actionable insights for environmental managers. By integrating OBIS biodiversity data with the World Register of Introduced Marine Species, the framework enables rapid identification of invasive threats and supports policy decisions.
